## Flags for the author (read before using this cluster)

1. **RFC 8446 is obsoleted by RFC 9846 (TLS 1.3, July 2026).** Wording of the PSK and 0-RTT text changed — cite RFC 9846 (see RFC-02).
2. **IEEE 802.15.6-2012 is superseded by IEEE 802.15.6-2026** (Board approval 2026-06-04, published 2026-08-28, "data rates up to 50 Mbps"). The per-PHY figures below are for the 2012 text, via secondary sources (see LNK-05).
3. **FIPS 206 (FN-DSA) has not been published as of 2026-09-27**, as a draft or as a final standard. The FN-DSA-512 sizes are SECONDARY and are the pre-FIPS Falcon-512 values (see PQC-03).
4. **"Energy Consumption Evaluation of Post-Quantum TLS 1.3 for Resource-Constrained Embedded Devices" is by Tasopoulos, Dimopoulos, Fournaris, Zhao, Sakzad, Steinfeld (ACM CF '23, 2023)**, not Roma/Tai/Hasan 2021. Fix the attribution in the bib.
5. In that energy paper, Table 2 and §4.2.2 print the label **"Dil1+Kyb1"**, but the notation sentence defines "Dil2+Kyb1" (Dilithium 2 + Kyber 512). The row's times match the ISPEC 2022 "Dil2-Kyb1" row. Confirm with the authors or the ACM version before labelling it Dilithium2.
6. pqm4 `benchmarks.md` does not name the board. The README says the Nucleo-L4R5ZI is "the default board for measurements". The pqm4 master branch changes over time, and the commit could not be captured (GitHub API returned 403; the commits page is disallowed by robots.txt).
7. RFC 7925 is a **TLS/DTLS 1.2** profile. Its TLS/DTLS 1.3 successor, draft-ietf-uta-tls13-iot-profile-25, is in the RFC Editor queue and "Updates RFC 7925" (see RFC-02).
8. PQ-TLS handshake times and energies (PQC-05) were measured over **wired Ethernet (mean RTT 0.493 ms)**, not over a constrained radio link. They are lab bench figures.
